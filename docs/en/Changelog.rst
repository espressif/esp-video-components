Changelog
=========

:link_to_translation:`zh_CN:[中文]`

This document records the description of each document update.

Version 0.1.0 (2026-04-16)
^^^^^^^^^^^^^^^^^^^^^^^^^^

- First interim version released.

Version 0.2.0 (2026-07-10)
^^^^^^^^^^^^^^^^^^^^^^^^^^

- Added and expanded English documentation, with synchronized updates to the Chinese documentation.
- Unified camera interface descriptions and fixed in-page cross-references, image paths, and some API names and file paths.

Version 0.3.0 (2026-08-31)
^^^^^^^^^^^^^^^^^^^^^^^^^^

- Documented ESP32-S31 (DVP/SPI/USB and JPEG hardware codec) and the JPEG hardware decoder video device (``/dev/video12``).
- Split JPEG encoder/decoder and H.264 encoder in the SoC and device-node tables; noted that H.264 hardware decode is not provided.
- Added an English entry for the ESP Video application development guide. The English text is not available yet; the page points to the Chinese documentation.
- Updated ``ESP_Video/commands.rst``: MIPI-CSI events, ``VIDIOC_RESTART``, motor formats, ``VIDIOC_SET_OWNER``, M2M buffer types, and the control ID overview.
